# lamps

Radiolaria-inspired lamp generator built as a Three.js single-page app.

## Run locally

Use Node.js 24 or newer. If you use nvm, run `nvm use` to select the version
specified by `.nvmrc`.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Included controls

- Morphology family
- Seed
- Body radius
- Shell thickness
- Axial stretch
- Symmetry order
- Spike bands
- Spike length
- Pore frequency
- Pore depth

## Research and precedent references

- Ernst Haeckel, *Kunstformen der Natur* — public-domain plates that emphasize lattice shells, pores, and spines
- Ernst Haeckel, *Report on Radiolaria* (HMS Challenger, 1887) — foundational shell and spine taxonomy
- Radiolaria.org — morphology imagery useful for spherical vs. elongated shell families
- `palletorsson/AdaResearch` radiolaria generator — a procedural Godot study of layered shells and spines
- `merrypranxter/botanical_illustration` — a Three.js shader gallery with Haeckel-inspired radiolaria plates
- Bernotat & Co, *Radiolaria Lamp* — a real-world lamp precedent for the form language
